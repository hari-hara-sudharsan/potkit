# Demo Notes

This folder contains visual assets and notes for the PotKit demo.

## Notes

- `docs/architecture.png` shows the 4-layer PotKit architecture:
  - Developer
  - PotKit CLI
  - Core Infrastructure
  - Blockchain Operations

- `docs/workflow.png` illustrates the 7-step PotKit developer workflow:
  - init
  - status
  - build
  - upload
  - faucet
  - logs
  - dev

- `screenshots/` contains placeholder images for future live command screenshots.

## How to use these assets

- Embed the diagrams in the README and documentation.
- Replace the placeholder screenshots with real UI output before final submission.
- Keep the visuals clean, minimal, and easy to scan.
